# Flashlight 1.3.1 release text

The text below is what goes into the GitHub release, the Nexus file description and the Nexus changelog line. The page text is `NEXUS.bbcode`. 1.3.0 was published on GitHub only, so the Nexus file for 1.3.1 also carries the 1.3.0 changes.

## GitHub release notes

Flashlight 1.3.1

- The shop sells fewer Dry Cells. The daily stock and the most a player may carry are 8 each, down from 16 each. With 10 hour batteries, 16 cells was 80 hours of light a day, and the yearly shop simulation never ran short even at 20 hours of light a day, so the limits did nothing. A `config.json` that still has 16 for either value is moved to 8 once, and a value you changed is kept.
- The balance document and the simulation are corrected for the 10 hour batteries and the 6g sell price.

Needs Stardew Valley 1.6.9 or newer and SMAPI 4.2.1 or newer. Three or more players, split screen and play over the internet are still untested.

## Nexus file description

Flashlight 1.3.1. Cone 10 tiles long (12 with a Battery Pack), batteries last 10 and 12 hours, Dry Cells 30g, and the shop now sells 8 a day with 8 carried at most.

## Nexus changelog line

1.3.1: 10 tile beam, longer batteries, Dry Cell 30g, shorter tooltip with +1 Coolness, shop limit lowered to 8 a day.
